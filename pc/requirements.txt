# No third-party packages required.

# All PC-side tools (udp_protocol.py, test_suite.py, generate_scurve_csv.py)
# run on the Python 3 standard library alone:
#   socket, struct, time, csv, argparse, math, os, datetime
#
# (numpy is permitted by the spec but intentionally NOT used.)
# This file intentionally lists no dependencies.
#
# Robot side: the ESP32-S3 runs MicroPython firmware (firmware/robot_firmware.py),
# NOT a pip package. Flash MicroPython once, then copy the firmware as main.py:
#   esptool.py --chip esp32s3 --port /dev/ttyUSB0 erase_flash
#   esptool.py --chip esp32s3 --port /dev/ttyUSB0 write_flash -z 0x0 ESP32_GENERIC_S3-<ver>.bin
#   mpremote connect /dev/ttyUSB0 fs cp firmware/robot_firmware.py :main.py
# (download the ESP32-S3 .bin from https://micropython.org/download/ESP32_GENERIC_S3/)
